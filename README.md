## 📂 Projetos em Destaque

**1. API Connect (`api-connect`)**
* **Descrição:** API RESTful desenvolvida em Python com Flask para o gerenciamento estruturado de usuários, aplicando arquitetura modular (Controllers, Routes, Data), validação de entrada, tratamento de erros com códigos HTTP padronizados (200, 201, 400, 404) e documentação completa.
* **Tecnologias:** Python, Flask, Git & GitHub.
* **Repositório:** [Acessar Projeto](https://github.com/MatheusCunhaDEV/api-connect)

**2. DriveLoc — Locadora de Veículos (SQL)**
* **Descrição:** Sistema de gerenciamento de locação desenvolvido em SQL puro. Contempla funcionalidades de cadastro, listagem, busca por placa, filtro por ano e remoção de registros.
* **Tecnologias:** SQL.

**3. Sistema de Senha com LCD Keypad Shield (Arduino / C++)**
* **Descrição:** Sistema de controle de acesso e validação de senha de 4 dígitos utilizando Arduino. Conta com leitura analógica de teclas, interface visual para senha, navegação com indicador, limite de 3 tentativas e bloqueio temporário com contagem regressiva em tempo real.
* **Tecnologias:** C++, Arduino, LiquidCrystal.
